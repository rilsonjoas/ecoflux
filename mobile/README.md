# Ecoflux — Mobile (Flutter)

Aplicativo mobile do Ecoflux. Responsável pela interface do usuário:

- Mapa do campus com pontos de descarte (OpenStreetMap)
- Consulta de tipos de resíduos por ponto
- Cadastro, autenticação e acompanhamento de pontuação/histórico
- Validação do código gerado pela lixeira

> Stack sugerida: **Flutter**. Criar com `flutter create mobile` quando a toolchain estiver instalada.
