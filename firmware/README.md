# Ecoflux — Firmware (ESP32)

Protótipo de **lixeira inteligente** baseado em ESP32. Funcionalidade adicional ao MVP:

- Interface física simples para seleção do tipo de resíduo
- Conexão Wi-Fi + HTTP/HTTPS
- Comunicação de cada descarte ao servidor
- Geração de **código único** exibido ao usuário para validação no site

> Escopo da implementação depende do tempo/recurso disponível — não é obrigatório para o MVP.
